DRAGONFALL ARENA - CLEAN UNITY 6.6 ASSETS

IMPORTANT:
This package is intended to REPLACE your existing Assets folder.
Do not merge it into the old Assets folder, because the old project has duplicate
C# scripts and duplicate TextMesh Pro example scripts.

1. Close Unity.
2. Make a backup of your project.
3. Rename your existing project folder's Assets folder to Assets_OLD.
4. Copy the Assets folder from this package into the project folder.
5. Open Unity 6.6.
6. Wait until import/compile finishes.
7. Open Assets/game/Scenes/DragonfallArena.unity.
8. Press Play.

Camera:
FOV 22
Local position (0, 20, -20)
Local rotation (50, 0, 0)

Controls:
WASD = Move
1 = Fire
2 = Tail
3 = Fly
